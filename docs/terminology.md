# Terminology

## Summary

### AWS 계정 컴퓨팅 스토리지

| Term | Abbreviation | Description | Detail |
|:---|:---:|:---|:---:|
| Amazon Web Services               | AWS       | 컴퓨팅, 스토리지, 네트워킹 등 다양한 클라우드 서비스를 제공하는 플랫폼입니다. | - |
| Identity and Access Management    | IAM       | AWS 사용자와 리소스의 접근 권한을 관리하는 서비스입니다. | - |
| Elastic Compute Cloud             | EC2       | AWS에서 가상 서버를 생성하고 실행하는 서비스입니다. | - |
| Elastic Block Store               | EBS       | EC2 인스턴스에 연결해 사용하는 블록 스토리지 서비스입니다. | - |

### AWS 네트워크 

| Term | Abbreviation | Description | Detail |
|:---|:---:|:---|:---:|
| Amazon Virtual Private Cloud      | VPC       | AWS에서 논리적으로 분리된 가상 네트워크를 구성하는 서비스입니다. | - |
| Internet Gateway                  | -         | VPC와 인터넷 간의 통신을 가능하게 하는 게이트웨이입니다. | - |
| Elastic IP                        | EIP       | AWS 리소스에 할당해 사용할 수 있는 고정 공인 IPv4 주소입니다. | - |

### 일반 네트워크 

| Term | Abbreviation | Description | Detail |
|:---|:---:|:---|:---:|
| Subnet                            | -         | 네트워크를 나누어 장치나 리소스를 배치하는 하위 네트워크입니다. | - |
| Route Table                       | -         | 네트워크 트래픽의 목적지와 경로를 지정하는 규칙 모음입니다. | - |
| Secure Shell                      | SSH       | 네트워크를 통해 원격 시스템에 안전하게 접속하는 통신 프로토콜입니다. | - |
