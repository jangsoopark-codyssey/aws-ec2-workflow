# Identity and Access Management (IAM)

## 개요

IAM은 AWS 리소스에 접근하는 주체의 인증과 권한을 관리하는 서비스이다. 인증은 “누구인가”, 인가는 “어떤 작업을 허용하는가”를 확인한다.

## 역할과 동작 방식

| 구성 요소 | 의미 |
|:---|:---|
| User | AWS 계정 안의 사용자 신원 |
| Group | 사용자에게 공통 권한을 부여하는 묶음 |
| Role | 신뢰하는 주체가 맡아 임시 자격 증명으로 사용하는 역할 |
| Policy | 허용하거나 거부할 작업과 대상 리소스 등을 정의하는 문서 |

권한 평가에서는 기본적으로 허용되지 않은 작업이 거부되며, 명시적인 거부는 허용보다 우선한다. 역할의 신뢰 정책은 누가 역할을 맡을 수 있는지, 권한 정책은 맡은 역할로 무엇을 할 수 있는지 정한다.

## EC2 실습에서의 사용

학습자는 필요한 리소스만 관리할 수 있는 전용 사용자 또는 역할을 사용한다. EC2 안의 애플리케이션이 AWS API를 호출해야 한다면 인스턴스 프로파일을 통해 IAM 역할을 연결하고 임시 자격 증명을 사용한다. 장기 액세스 키를 소스 코드에 저장하지 않는다.

## 주의사항

일상 작업에 루트 사용자를 사용하지 않고 최소 권한을 적용한다. IAM 권한은 일반적인 SSH 로그인용 개인 키나 TCP 포트 허용 설정을 대신하지 않는다. SSH 접속은 운영체제 계정, 키, 네트워크 설정도 별도로 확인해야 한다.
