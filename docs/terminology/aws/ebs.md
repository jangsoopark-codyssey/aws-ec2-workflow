# Elastic Block Store (EBS)

## 개요

Amazon EBS는 EC2에 연결하여 디스크처럼 사용하는 영구 블록 저장소이다. 운영체제, 애플리케이션 파일, 데이터베이스 파일 등을 저장한다. 객체를 저장하는 S3와는 사용 방식이 다르다.

## 역할과 동작 방식

EBS 볼륨과 연결할 EC2 인스턴스는 같은 AZ에 있어야 한다. 인스턴스 하나에 여러 볼륨을 연결할 수 있으며, 일반적인 구성에서는 볼륨 하나를 인스턴스 하나에 연결한다. 일부 볼륨과 인스턴스 유형은 별도 조건에서 Multi-Attach를 지원한다.

새 데이터 볼륨은 운영체제에서 장치를 확인하고 필요에 따라 파일 시스템을 생성한 뒤 마운트해야 한다. 기존 데이터가 있는 볼륨을 포맷하면 데이터가 손실된다.

## EC2 실습에서의 사용

루트 볼륨은 운영체제가 설치된 디스크이다. 실습에서는 필요한 용량을 정하고 볼륨 유형, 암호화, 종료 시 삭제 설정을 확인한다. 스냅샷은 볼륨의 백업에 사용하며 다른 AZ에서 볼륨을 생성하는 데도 활용할 수 있다. 애플리케이션 데이터의 일관성을 고려해 백업해야 한다.

## 주의사항

EC2를 중지해도 EBS 데이터는 유지되며 볼륨 비용이 계속 발생할 수 있다. 인스턴스 종료 시 볼륨이 남는지는 `DeleteOnTermination` 설정에 따라 다르다. 인스턴스와 분리된 볼륨 및 스냅샷도 정리 대상인지 확인한다. EBS와 임시 저장소인 instance store를 혼동하지 않는다.
