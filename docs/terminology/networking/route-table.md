# Route Table

## 개요

라우팅 테이블은 목적지 주소에 따라 트래픽을 어느 대상으로 전달할지 정하는 경로 목록이다. AWS에서는 서브넷과 연결하여 해당 서브넷의 라우팅을 결정한다.

## 역할과 동작 방식

경로는 목적지(Destination)와 대상(Target)으로 구성된다. 여러 경로가 일치하면 더 구체적인 주소 범위, 즉 가장 긴 접두사의 경로를 우선한다.

다음은 `10.0.0.0/16` VPC의 퍼블릭 서브넷을 위한 IPv4 경로 예이다.

| Destination | Target | 의미 |
|:---|:---|:---|
| `10.0.0.0/16` | `local` | VPC 내부 통신 |
| `0.0.0.0/0` | `igw-…` | 더 구체적인 경로가 없는 IPv4 목적지는 인터넷 게이트웨이로 전달 |

`10.0.1.10`으로 보내는 패킷에는 기본 경로보다 구체적인 `local` 경로가 적용된다.

## AWS에서의 사용

각 서브넷은 한 번에 하나의 서브넷 라우팅 테이블을 사용한다. 명시적으로 연결하지 않으면 VPC의 기본(Main) 라우팅 테이블을 사용한다. 하나의 라우팅 테이블을 여러 서브넷에 연결할 수도 있다.

실습에서는 기본 경로를 추가한 테이블이 EC2의 서브넷에 실제로 연결되어 있는지 확인한다. 다른 테이블을 수정하면 기대한 경로가 적용되지 않는다.

## 주의사항

경로는 패킷의 전달 방향을 정할 뿐 TCP 22나 80 같은 포트의 접근을 허용하는 규칙이 아니다. 포트 접근은 보안 그룹, Network ACL 및 운영체제 방화벽에서 별도로 확인한다. `0.0.0.0/0`은 모든 IPv4 목적지이며 IPv6 기본 경로인 `::/0`과 구분한다.
