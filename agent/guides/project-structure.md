# Project Structure

The repository documents AWS EC2 and networking concepts. Check the current tree before adding files.

- `README.md`: repository entry point.
- `docs/terminology.md`: glossary summary with English terms, abbreviations, and Korean descriptions.
- `docs/terminology/aws/`: AWS topic files, such as `ec2.md`, `iam.md`, and `vpc.md`.
- `docs/terminology/networking/`: networking topic files, such as `ssh.md`, `subnet.md`, and `route-table.md`.

Detailed topic documents live under `docs/terminology/`. Keep glossary links aligned with these paths and inspect existing topic files before creating duplicates.

Mission artifacts, if requested, belong under `docs/`: `architecture.(png|pdf)`, `troubleshooting.(md|pdf)`, `cleanup-checklist.md`, and evidence images in `docs/evidence/`.
