# Development and Validation

This is a documentation repository with no application source, build system, package manifest, or configured test runner.

Before editing, inspect files with `rg --files` (or `rg --files docs` for documentation topics). Preview changed Markdown and check heading hierarchy, tables, image readability, and relative links. Ensure the README, diagram, troubleshooting report, and cleanup checklist agree when multiple artifacts change.

Run `git diff --check`, then review `git diff --stat` and `git diff`. Do not report tests, deployment, external access, or cleanup as completed unless actually performed.
