# AWS EC2 미션 인계

- **Updated:** 2026-11-18
- **Project/task:** AWS EC2 웹 서비스 배포 미션의 문서 기반 구성 및 후속 실습
- **Repository/branch:** `aws-ec2-workflow` / `main`

## 목표

서울 리전에 EC2 웹 서비스를 구성하고 외부 접속을 검증한 뒤, 아키텍처·실제 오류 대응·접속 증빙·리소스 정리 결과를 문서화하는 학습 미션. 현재까지는 미션 수행을 위한 기본 문서 구성 단계.

## 현재 상태

| 항목 | 확인된 상태 |
|:---|:---|
| 용어 문서 | 요약 1개와 상세 10개 완성, 상호 링크 및 공식 참고 자료 포함 |
| 문체 | 본문은 `~한다`, `~이다`의 문어체, 요약표는 명사형 중심의 개조식 |
| 실습 체크리스트 | 계정 준비부터 리소스 정리까지 구성, 모든 항목 미체크 |
| README | 제목과 섹션 골격만 존재. `asdf` 등 임시 내용 교체 필요 |
| 에이전트 운영 문서 | 작업별 지침, 검토·커밋 절차, 인계 지침과 템플릿 존재 |
| 실제 AWS 작업 | 계정 준비, 리소스 생성·배포·접속·정리 여부 모두 미확인 |
| 제출 증빙 | 아키텍처 이미지, 접속 증빙, 오류 보고서, 정리 결과 문서 없음 |

체크리스트의 미체크 상태는 실제 AWS 리소스가 없다는 증거가 아님. 외부 환경의 상태는 별도 확인 필요.

## 결정 사항과 제약

- 사용자 선호: 한국어 설명은 경어체 대신 문어체 또는 개조식 사용. AWS 서비스명과 표준 기술 용어는 영어 유지.
- 상세 문서의 최종 경로는 `docs/terminology/`. 과거 오타 경로 `docs/termonology/`는 사용하지 않음.
- 기본 구성: 서울 `ap-northeast-2`, VPC 1개, 퍼블릭 서브넷 1개, Internet Gateway, 기본 경로 `0.0.0.0/0 → IGW`, EC2 웹 서버.
- HTTP TCP 80은 외부 공개, SSH TCP 22는 학습자의 현재 공인 IP 또는 지정 범위로 제한. 전체 포트 공개 금지.
- 루트 계정으로 리소스 작업 금지. 필요한 권한의 IAM 사용자 또는 역할 사용, `AdministratorAccess` 금지.
- 내부 HTTP 200, 아웃바운드 인터넷 통신, 외부 웹 접속 검증 필요. HTTPS와 Docker는 선택 사항. Elastic IP도 고정 주소가 필요할 때 선택.
- 무료 사용 보장 금지. 계정별 적용 조건과 비용 확인 필요.
- 비밀 값·개인 키 기록 금지. 사용자 명시 요청 없이 AWS 리소스 생성·변경·삭제 금지. 이번 요청은 인계 문서 작성만 승인한 상태.
- 예시 명령, 계획, 실제 실행 결과를 구분. 오류 사례와 검증 결과를 만들어 내지 않음.
